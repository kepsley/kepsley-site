# Kepsley brand homepage — 2026-11-14

The new English, Simplified Chinese and Japanese homepages present Kepsley as a personal memory butler. The approved warm composition was recolored at the user's request to a technology palette: deep navy `#081426`, ice-blue `#e8f3ff` and cyan `#69d9ee`. No app screenshots, download/TestFlight links, registration, pricing or purchase calls to action were added.

## Implementation

- Static HTML generated from `scripts/build_home.py`; no client JavaScript or new dependencies.
- Dedicated `site/assets/home.css`; six privacy/support pages and their original `style.css` verified byte-for-byte unchanged.
- Original SVG brand mark, memory landscape and scene illustrations; static 1200×630 PNG sharing image generated from `share.svg`.
- Localized title/description, canonical URLs, all language alternates, Open Graph and Twitter metadata.
- Main CTA navigates to the explanation section; header links target the scenes/about sections. Language links preserve the existing home routes.
- Illustrative content is explicitly labeled. Copy describes recording, organizing and revisiting rather than unimplemented automatic listening or autonomous task execution.

## Verification

Chrome DevTools MCP was used for browser checks.

- English, Chinese and Japanese checked at 375, 390, 768 and 1440 px: no horizontal overflow, no text-container overflow, and all images loaded.
- The mobile/tablet card-label collision found in the initial composition was corrected by increasing the illustration canvas height. Chinese 375 px was rechecked: postcard bottom 966.66 px, example-label top 984.55 px.
- Reduced-motion emulation: zero active animations; smooth scrolling disabled by the media query.
- Keyboard Tab reaches the visible skip link with its focus outline; Enter navigates to `#main`. Main CTA verified to navigate to `#how`.
- Language menu exposes English, 简体中文 and 日本語, with the correct current-page indication and destinations.
- All nine local routes returned HTTP 200 with the correct language, title and heading. Static checks validate local resources, anchors, generated-page consistency and allowed public file types.
- No resources were requested from third-party origins by the homepage.
- Text contrast: body 16.42:1, secondary text against the brightest background 6.83:1, accent 10.51:1, button 11.98:1, card labels 7.24:1.
- `python3 scripts/check_site.py` and `git diff --check` pass.
