01

Free and Pro

Recording, import, playback, export and access to existing text are free. Pro is a one-time purchase at the price displayed by Apple. It unlocks offline transcription, speaker labels, AI proofreading, summaries, personal terminology, AI naming, and manual or optional automatic iCloud backup. Cloud AI uses your own API key and is charged separately by the provider.

02

Transcribe and review

Save or import audio, open Transcript and Summary, select Mandarin, English or Japanese, then Transcribe. No API key is needed for local recognition. Check estimated speaker labels and uncertain speech. Edit as New Version preserves the original. History groups related versions; expand All Versions. Before summarizing, choose the exact text source. Partial text is usable with an incompleteness warning.

03

Listen to text

Open a transcript, corrected text or summary and choose Read Aloud. You can also read a selected speaker. Available system voices are used; there is no cloud voice fallback. Pause, resume and stop from the app or playback controls. Recording stops read aloud. Calls or headset disconnection may pause playback; resume manually.

04

AI configuration

Use your own valid text-service key and supported model. Test Interface sends only fixed test text after confirmation and may cost money; it does not test audio transcription. Review the destination before sending private text. File/JSON/QR configuration sharing includes readable keys; send only to trusted recipients. Revoke a shared key through its provider if needed.

05

Long recordings and interruptions

Start recording in the foreground. Available inputs can recover automatically; phone/Siri interruptions resume only if the system permits and you have not cancelled. Gaps are possible. Saved recordings retain short segments; closed segments compress when possible. Stop does not merge the full recording. Export creates one M4A and needs extra storage. Checkpoints are local recovery, not an external backup. Phone/WeChat call audio capture and live translation are not supported.

06

Power, background and recovery

Transcription can consume significant battery. Foreground transcription/proofreading/summary keeps the screen awake; connect power for long tasks. iOS controls background processing. If paused or expired, return and continue from saved progress; unfinished work may repeat. Force-quitting can interrupt tasks. Cloud requests with unknown outcomes may already be charged. Preserve the app and drafts after a failure, free other space, and retry; do not uninstall to recover data.

07

Contact

Email otsgame@yahoo.com with app/iOS version, device/headset model, steps and expected/actual result. Do not send passwords or unnecessary recordings. Existing privacy terms for correspondence apply.

08

iCloud backup and restore

Pro offers manual backup and optional automatic backup to your private iCloud database. Backups include saved recordings, tags and AI results, plus optional non-sensitive settings; API keys are excluded. Automatic backup is off by default. Enabling it allows Wi-Fi and cellular uploads using your own iCloud storage; additional storage is not included. Background scheduling depends on iOS. Restores are always manual, including on another device. Deleting local recordings does not delete cloud backups. Backup state errors may stop transfers to protect existing data. This is backup, not automatic cross-device synchronization.

09

AI processing queue

Confirmed AI tasks run one at a time, with up to 10 waiting tasks. Recording can continue while AI processes saved recordings; resource limits may pause AI. Reopen the app and manually continue a suspended queue. Cancelling does not undo data already sent or provider charges. Retained progress and source text remain available where saved; check each task’s status before retrying.
